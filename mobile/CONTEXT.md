# Goals and recurring tasks

This context defines how a goal’s time horizon and its linked task schedule relate in SnapFocus.

## Language

**Goal duration**:
The goal’s time window, set as one positive number of days, weeks, or months from its start date. The goal bar shows elapsed time in this window; tracked focus minutes are shown separately as activity, not compared to a user-set target.
_Avoid_: Goal period, progress reset period

**Task repeat schedule**:
The cadence on which a linked task appears: daily, on selected weekdays, or monthly on a selected day.
_Avoid_: Goal duration, goal period

**Focus minutes**:
The accumulated tracked time spent on tasks linked to a goal. It is activity history and does not determine the time-window progress bar.
_Avoid_: Count goal
